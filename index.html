como começou

De aparelho quebrado a laboratório de estudo

A tela do S21+ parou de funcionar, mas o resto do aparelho continuava perfeito: processador, memória, rede, bateria. Em vez de deixar guardado, a ideia foi transformá-lo em um pequeno servidor doméstico.

A primeira decisão importante veio logo no início: em vez de tentar dar root ou trocar o sistema operacional, o Android ficou como está — sem root, com SELinux em modo Enforcing. Todo o trabalho de servidor acontece dentro do Termux, um ambiente Linux de usuário que roda sobre o próprio kernel do Android.

Isso manteve o aparelho estável e, ao mesmo tempo, deu acesso a um ambiente Linux completo: SSH, Python, NGINX, supervisor de serviços, tudo isso sem tocar no sistema base.

o painel de status

Uma API que prefere dizer "não sei" a inventar um número

O Android 15 restringe o acesso a partes do /proc. Quando a API não consegue medir algo com confiança — como o uso de CPU — ela retorna null em vez de simular um valor.
